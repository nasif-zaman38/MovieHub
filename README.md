# Java OOP Practice

This repository contains my Java Object-Oriented Programming practice tasks and small console-based applications.

Each task focuses on applying Java and OOP concepts through practical examples.

---

## Tasks

### 1. MovieHub

**Task Name:** MovieHub

**Task Objective:**  
Build a console-based movie management application where users can view, search, add, remove and manage favorite movies.

**Key Things Learned:**

- Inheritance                        
- Encapsulation
- Constructors
- List, ArrayList
- Searching and Filtering

**How to Run/Test:**

```bash
cd MovieHub
mvn compile
mvn exec:java
```

Or run `Main.java` directly from IntelliJ IDEA.
